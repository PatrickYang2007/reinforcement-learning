# Reinforcement Learning Projects

Two projects from Cornell CS 4789/5789 (Introduction to Reinforcement Learning), Fall 2026, each built on starter code provided by the course staff.

| Project | Summary |
|---|---|
| [Policy Learning for Recommendation](policy-learning-for-recommendation/) | Softmax and Plackett–Luce ranking policies trained with policy gradients on a simulated recommender |
| [Bear Stories with GRPO](bear-stories-with-grpo/) | Post-trains the TinyStories-33M language model with GRPO to write stories about bears |
